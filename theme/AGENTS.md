# Theme rules

- Keep presentation in CSS, not Go strings or component markup.
- Default CSS source and rules: [default design system](default/AGENTS.md).
- Theme adapter contract, token requirements, and computed-style verification:
  [theme guide](../docs/guides/themes.md#theme-adapter-contract). Keep it as
  the single source of adapter behavior requirements.
- Each adapter's `adapter.css` is editable source. `framework.css` and
  `LICENSE.txt` are generated by `npm run build:themes`; preserve upstream
  notices. Never modify installed `node_modules` files.
- Changes to upstream selector mapping belong in
  [build-themes.mjs](../scripts/build-themes.mjs).
- Check layout and component variants across all supported adapters after CSS
  changes. Keep inline output self-contained without runtime asset reads.
