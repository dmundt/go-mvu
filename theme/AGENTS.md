# Theme rules

- Keep presentation in CSS, not Go strings or component markup.
- Default CSS source and rules: [default design system](default/AGENTS.md).
- Theme tokens and computed-style verification live in
  [theme guide](../docs/guides/themes.md).
- `open-props.css` and its license are generated by
  `npm run build:themes`; preserve upstream notices. Never modify installed
  `node_modules` files.
- Check layout and component variants in the default theme after CSS changes.
  Keep inline output self-contained without runtime asset reads.
