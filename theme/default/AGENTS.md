# Default design system rules

- Files embedded by package `theme` in order: `open-props.css`, `base.css`,
  `default.css`, `shared.css`. No Go package here (`default` = keyword).
- `open-props.css`, `LICENSE-open-props.txt`: generated by
  `npm run build:themes`. Never edit by hand.
- Use Open Props tokens (`--size-*`, `--gray-*`, `--indigo-*`, `--blue-*`, `--radius-*`,
  `--shadow-*`, `--font-*`, `--ease-*`) over literals. New token → rerun
  build. Never include `props.colors-oklch.css` (defines `--color-*` on `*`).
- `base.css`: unscoped, plain. Palette, public `--color-*` tokens, structure,
  tables, layout.
- `default.css`: every selector scoped to `html[data-theme-name="default"]`
  (`:where(...)` for low specificity). Unwrapped only to beat `base.css` or
  `shared.css`.
- `shared.css`: class selectors only.
- Target: dense, neutral, business/technical apps. Keep light, dark, system
  dark palettes in sync. Check users, components, themes examples at 1280px
  and 390px after changes.
- Verify: `npm run test:themes`, `go test ./...`.
